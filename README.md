# Limbus DIY 人格网页编辑器（PWA 版）

这是可直接上传 GitHub Pages 的完整静态项目。手机安装后会以独立应用窗口运行，并通过 Service Worker 缓存页面资源与已加载过的 Wiki 图标。

## 文件

- `index.html`：页面结构
- `style.css`：全部样式
- `app.js`：编辑器、实时预览、导出、自动关键词染色、PWA 安装逻辑
- `manifest.webmanifest`：PWA 清单
- `sw.js`：离线缓存
- `icons/`：PWA 图标
- `.nojekyll`：避免 GitHub Pages 走 Jekyll 处理

## 上传 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 把本目录里的**所有文件和文件夹**上传到仓库根目录。
3. 打开仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/(root)`，保存。
6. 等 GitHub 给出 `https://你的用户名.github.io/仓库名/`。
7. 用手机 Chrome / Edge 打开这个 HTTPS 地址。
8. 点网页里的 `安装 PWA`；如果浏览器不弹窗，就在浏览器菜单里选“安装应用 / 添加到主屏幕”。

## 更新网页后为什么手机还是旧版？

PWA 有缓存。当前 Service Worker 的版本号是：

```js
const CACHE_VERSION = 'limbus-diy-pwa-v1';
```

以后你改了代码并上传 GitHub，可以把 `sw.js` 里的 `v1` 改成 `v2`、`v3`……强制客户端更新缓存。

## 离线说明

编辑器主体会完整离线可用。Wiki 的罪孽框、状态图标是运行时远程加载的；某个图标在线显示过一次之后，Service Worker 会把它缓存下来，之后离线仍可继续显示。没有加载过的新 Wiki 图标在完全断网时无法首次获取。

## PNG 保存

手机保存逻辑按实际页面尺寸导出：普通页面为 1767×2048，超长技能页和被动页会自动增高。保存时会临时生成无 transform 缩放的副本，因此最终图片不会缩在左上角。

`html2canvas` 已随项目内置，离线时也能导出 PNG。如果浏览器不支持该渲染器，编辑器会尝试走自身的 SVG / Canvas 回退方案。

## 直接本地打开

双击 `index.html` 仍能使用大部分编辑器功能，但 `file://` 环境不能注册 Service Worker，所以不能获得真正的 PWA 安装和离线缓存。正式使用建议 GitHub Pages。

## v4 图标修复

此前技能罪孽框和关联状态图标通过 wiki.gg 外链加载，部分浏览器会因跨域/CORS或站点防盗链直接显示破图。

v4 已将这些位置改为页面内置 SVG/CSS 绘制：

- 七罪技能框：内置矢量绘制，支持 1/2/3 级框样式。
- 七罪中心标识：内置矢量文字标识。
- 流血、沉沦、束缚、迅捷、易损、守护、麻痹、烧伤、震颤、破裂、呼吸、充能等关联状态：内置小图标。
- 自定义/未知状态：自动使用名称首字作为兜底。

因此技能页预览、PWA 离线、PNG 导出均不再依赖外站图片，也不会出现浏览器的破图图标。

如果手机已经安装过旧版 PWA，推送 v4 后重新打开两次即可让 Service Worker 更新；仍看到旧版时可在浏览器站点设置中清除该站点缓存后再打开。

## v5：真实技能边框（推荐）

网页现在已经取消手绘 SVG 技能框，改为真实 Limbus 技能边框素材。

为了让 GitHub Pages / PWA 完全本地、离线也能用：

1. Windows 双击 `scripts/下载真实技能边框.cmd`。
2. 脚本会下载 21 个七罪 × S1/S2/S3 技能框，以及 7 个罪孽图标。
3. GitHub Desktop 会看到 `assets/` 下新增的 28 个文件。
4. Commit → Push origin。

网页会优先读取仓库内的 `assets/`；若你还没运行下载脚本，会自动回退到公开素材 CDN，因此不会再显示之前那种手绘抽象框。


## v8.9 手机刷新修正
- app.js / style.css 使用版本参数，避免手机继续吃旧缓存。
- Service Worker 对应用壳改为 network-first，并在新 SW 接管后自动刷新一次。
- LCB 技能图标本地缺失时自动回退到 EldritchTools CDN；Counter 守备再回退通用 Counter 图标。
- 发布 GitHub Pages 时仍建议把本地下载后的 assets 一并 Commit + Push，以获得完整离线体验。

## v9.0 输入卡死修正
- 修复技能文本框每输入一个字符就重建整个技能编辑器 DOM 的问题。
- 技能输入期间不再调用 renderEditors()，因此光标、焦点、中文输入法组合态不会被反复打断。
- 预览改为 70ms 防抖刷新，连续输入时只在短暂停顿后重绘预览。
- 技能卡编辑器标题用局部 textContent 更新，不需要重建整栏。
- 基础信息、硬币、被动、状态编辑也改为防抖预览刷新，降低电脑和手机端输入抖动。

## v9.1 技能页尺寸自适应
- 技能效果过长时，技能页会按内容自动增高，普通长度仍保持 1767×2048。
- 技能页 PNG / SVG 导出使用预览中的实际高度，避免长技能被裁切。
- 手机预览会随屏幕宽度缩放，并为增高后的页面保留正确的滚动空间。

## v9.2 被动页 PNG 导出修复
- 本地内置 html2canvas 1.4.1，避免外部脚本加载失败；许可证见 `assets/vendor/LICENSE-html2canvas.txt`。
- 关联状态图标改用兼容 PNG 渲染器的颜色样式。
- SVG 备用导出改用 XML 序列化，并在编辑器显示实际导出格式。

## v9.3 技能图标导出修复
- 导出前把技能图标的罪孽染色与裁切绘入临时图片，使 PNG 中的图标与预览一致。
- 原始技能图标和项目数据保持不变。

## v9.4 被动页尺寸自适应
- 被动和状态内容超出原画布时，被动页自动增高，支援被动不再被页脚裁切。
- 被动页 PNG / SVG 导出使用增高后的实际尺寸。
